# Contributing

FLICK is a portfolio product and external beta.

1. Open an issue describing the user problem before a substantial change.
2. Preserve private-by-default records and the distinction between Light and Core.
3. Run `npm run check` and `npm run build:web` before opening a pull request.
4. Do not add API keys, personal review data, copyrighted poster files, or production exports.
5. Update `docs/DECISIONS.md`, `docs/RELEASE_CHECKLIST.md`, and `docs/HANDOFF.md` when behavior or release scope changes.
