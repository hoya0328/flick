# ART BIBLE

## 시각 방향

FLICK는 영화의 몰입감과 기록의 가벼움을 함께 보여준다. 포스터와 사용자 감정이 중심이며 장식보다 빠른 선택과 읽기 흐름을 우선한다.

## 기본 토큰

- Primary: `#F2233C`
- Primary pressed: `#D91D34`
- Background: `#F7F8FA`
- Surface: `#FFFFFF`
- Text: `#15171A`
- Muted text: `#69707A`
- Border: `#E7E9ED`
- Typography: Pretendard, 시스템 글꼴 fallback
- Radius: 작은 태그 999px, 카드 16px, 모달 24px
- Spacing: 4px 기준, 화면 좌우 여백 20px

## 컴포넌트 규칙

- 포스터는 원본 비율을 유지하고 둥근 모서리로 자르되 얼굴·제목을 임의로 가리지 않는다.
- 감정 키워드는 색만으로 의미를 구분하지 않고 텍스트와 선택 상태를 함께 표시한다.
- 중앙 FLICK 행동은 기록 시작에만 사용하며 화면마다 의미를 바꾸지 않는다.
- AI 제안에는 `AI 제안` 배지를 표시하고 사용자 입력과 시각적으로 구분한다.
- 비공개·공개·스포일러 상태는 저장 버튼 가까이에서 확인한다.

## 모션

- 기본 전환 160~240ms, 감속 곡선 사용
- 스와이프는 다음 카드 방향과 결과를 미리 보여준다.
- 저장 성공은 짧은 색상·진동 피드백으로 표시한다.
- 로딩 애니메이션은 진행 상태를 숨기지 않으며 모션 감소 설정에서 축소한다.

## 플랫폼 대응

- iOS는 safe area, 키보드, 스와이프 뒤로가기와 Dynamic Type을 우선한다.
- 웹은 480px 이하에서 앱과 동일한 하단 탭을 사용하고 넓은 화면에서는 탐색을 좌측 또는 상단으로 이동한다.
- Android는 시스템 뒤로가기와 Material 동작을 따르되 브랜드 색과 정보 구조는 유지한다.

## 자산과 권리

- 로고와 아이콘은 원본 FLICK 자산만 사용한다.
- 영화 포스터·스틸·예고편은 공급자 사용 조건과 출처 표기를 따른다.
- 제공된 화면은 구조와 분위기 기준이며, 실제 컴포넌트는 접근성과 반응형 규칙에 맞게 재작성한다.
