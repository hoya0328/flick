# FLICK 글씨 홈 이동

## 범위 / 결정

- 사용자 요청: 왼쪽 심볼뿐 아니라 상단 FLICK 글씨로도 홈 이동.
- 홈·탐색·피드·마이 헤더가 공통 `HomeWordmark`를 사용한다. 일반 헤더는 `router.navigate('/')`, 마이는 기존 심볼의 `onHome` 콜백을 그대로 공유한다.
- 벡터 그림116.4×22px/위치 유지,44px 높이의 독립 Pressable, 버튼 역할·한국어 이름·키보드 Enter/Space 지원. 검색/알림/설정 버튼이나 헤더 전체에 홈 이동을 걸지 않는다.
- 로그인/전시 BrandMark, 기록 입력·저장·권한·DB·AI·무료5일 운영 기한·호스팅 프로젝트/별칭은 변경하지 않는다. 작성 중 폼에 새로운 강제 이탈 버튼을 추가하지 않았다.

## 검증

- TypeScript와 lint 통과.
- 관련6파일60테스트 통과(`home-wordmark`, `ui-polish`, `home-model`, `feed-service`, `feed-model`, `profile`). 이 중 신규 홈 글씨 계약6건. 전체 suite/보안 감사 재통과로 표현하지 않는다.
- 벡터 원본 검사, 기존 보안 호환 패치 검사, 소스/웹 빌드 비밀정보 검사,48경로 정적 웹 빌드 통과.
- 로컬 독립8084 데모에서402px 홈/탐색/피드/마이 글씨 클릭·Enter·Space 후 `/` 확인.320px 피드/마이 클릭·탐색Enter 확인, 홈 문서 넘침0px, 마이 헤더 시각 확인. 글씨 버튼 약116.39×44px이며 기존 벡터 크기는 그대로다.
- 실제 회원 기록 변경, 게시·업로드·AI 호출 없음. 기본 계정과 다른 로컬 포트의 기존 데모로 검사했다.
- 최종 JS `entry-288f9c8c8dc5b6496196cdafa170c94c.js`.
