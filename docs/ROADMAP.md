# ROADMAP

## 0. 가설 검증

- 핵심 사용자 5~8명 인터뷰
- 키워드 선택, 영화 상세, 두 기록 모드의 클릭형 프로토타입 테스트
- Light/Core 기록 완료 시간·이탈 질문·AI 비평 가이드 신뢰도 측정
- 외부 영화 데이터 제공 조건 조사

완료 기준: 사용자가 설명 없이 한 편의 기록을 끝내고, 다수가 기존 기록 방식보다 다시 쓸 의향을 보인다.

## 1. 개인 기록 MVP

- 계정과 취향 온보딩
- 영화 검색·상세·키워드 추천
- 감상일, 별점, 가볍게/집중해서 기록
- AI 키워드·비평 질문·초안 보조와 사용자 최종 편집
- 개인 기록 목록, 캘린더, 취향 리포트 1차 버전
- 개인정보·AI 표시·삭제 기본 정책

완료 기준: 클로즈드 베타에서 첫 기록 활성화율과 4주 내 두 번째 기록률을 측정할 수 있다.

## 2. 베타 개선

- 질문 수와 키워드 체계 최적화
- 추천 이유 설명과 개인화 개선
- 중간 저장, 오류 복구, 접근성, 알림 조정
- 취향 리포트의 정확도·이해도와 공유 방식 개선

## 3. 선택적 소셜 확장

- 공개 범위와 스포일러 제어
- 피드, 팔로우, 댓글, 좋아요, 스크랩
- 신고·차단·운영 도구
- 큐레이터·매거진 운영 실험

소셜 기능은 개인 기록만으로 재방문 가치가 확인된 뒤 진행한다.
