# 무료 커뮤니티·PWA v1 — 2026-10-27

사용자의 ‘유료가 필요하지 않은 남은 작업 개발’ 요청으로 팔로우/일상 피드/공개 프로필/인앱 알림 보류를 해제한다. 기존 데이터·무료 한도·배포 대상을 보존한다.

- 프로필 공개 기본 OFF. 사용자가 회원에게 공개를 선택하면 닉네임·소개·사진·공개 완료 리뷰/공개 컬렉션/공개 일상 글만 표시한다. 이메일·비공개 기록·관심 영화·취향 분석은 공개하지 않는다. 기존 profiles RLS는 넓히지 않는다.
- 공개 프로필은 로그인 회원 대상이다. 공유 링크는 로그인 후 해당 공개 프로필로 복귀한다. 데모는 서버 커뮤니티에 쓰지 않는다.
- 팔로우는 공개 프로필만 대상, 자기 자신 금지, 중복 방지. 관계 목록은 본인 전용이고 다른 사람의 관계 목록은 공개하지 않는다. 탈퇴/프로필 비공개 전환에도 콘텐츠 접근 권한이 확장되지 않는다.
- 일상 글: 본문 1~2,000자, 사진 최대 5장, 나만 보기 기본값. 사진은 기존 비공개 core-photos/장당 250KB/계정 누적16·전체160장 한도 공유. Figma 15:501의 41px 작성자/14px 본문·22.8px 행간/359px 사진·가로 여백21 기준을 재사용한다. 디자이너 샘플 글·사진·수치는 복제하지 않는다.
- 작성/수정은 본인만, 삭제는 7일 휴지통(이후 복구 불가), 운영자 숨김은 작성자가 복구할 수 없다. 일상 글 공감·단일 댓글·저장·신고를 제공하고 기존 리뷰/답글 흐름은 유지한다. 글/댓글의 생성 한도는 서버에서 검증한다.
- 인앱 알림만: 팔로우, 공개 리뷰·일상 글 공감/댓글. 원문·이메일을 알림에 복제하지 않고 읽을 때 대상 권한을 재검사한다. 자기 알림 제외, 동일 공감/재팔로우 중복 억제, 최근30일·페이지 제한. 이메일/OS 푸시·DM·외부 알림 업체 없음.
- 새 게시물 운영 권한은 기본 OFF이며 기존 super_admin만 본인 권한을 명시적으로 켤 수 있다. 신고 목록/운영자 숨김은 그 권한을 재검사하고 감사 로그를 남긴다. 기존 계정·기록 운영 권한은 바꾸지 않는다.
- PWA: 설치 안내·manifest·벡터 원본 기반 앱 아이콘·오프라인 안내. 공개 정적 자산만 캐시하고 Auth/Supabase/API/개인 데이터·서명 사진 URL은 캐시하지 않는다. 네트워크가 없을 때 저장됐다고 표시하지 않는다. 서비스워커 업데이트로 작성 중인 화면을 강제 새로고침하지 않는다.
- QA: 사용자 실제 계정 삭제/운영DB 복원 금지. 두 계정 트랜잭션 QA 및 합성 계정 cascade 검증, 복구용 도구의 dry-run/합성 데이터 시험을 실제 재해 복구와 구분한다. 백업이 GitHub 소스만으로 충족된다고 주장하지 않는다.
- 외부 음성·유료 SMTP·유료 호스팅·다른 AI 업체·유료 큐/검색을 연결하지 않는다. 무료 한도 초과/보안 검증 실패 시 중단·안내한다. 운영 배포는 기존 EAS beta만 사용한다.
- 롤백: `rollback/free-community-before-2026-10-27`. 추가 데이터를 삭제하는 롤백은 하지 않는다.
