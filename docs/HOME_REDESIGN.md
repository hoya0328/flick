## 기능 연결과 콘텐츠 원칙

- 실제 영화·공개 리뷰·랭킹·전문가 큐레이션은 기존 Supabase 읽기 경로를 사용한다. 공감과 저장은 기존 RPC만 호출한다. 비공개/초안은 공개 피드에 노출하지 않는다.
- 공개 데이터가 비어 있거나 데모인 영역은 Figma의 예시 콘텐츠를 명시적으로 표시한다. 예시를 눌러도 사용자 리뷰·전문가 콘텐츠를 위조하거나 공감·저장·댓글을 서버에 만들지 않는다. 영화 예시는 해당 제목 검색으로 연결한다.
- 오래된 랭킹과 부족한 표본을 진짜 이번 주 순위로 표시하지 않는다. 대체 추천의 평점은 TMDB 10점 척도를 5점으로 변환하고, 공개 리뷰 수를 별점으로 오인하지 않게 구분한다.
- Figma의 조회수/키워드 사용량 숫자는 디자인 예시이므로 실제 집계가 없을 때 복제하지 않는다. Light 피드 RPC가 제공하지 않는 감독·태그를 다른 영화 데이터에서 임의로 붙이지 않는다. 스포일러 본문은 기존처럼 숨긴다.
- `/feed`에서 Light/Core 목록, 댓글 진입, 공감/저장, 랭킹, 니치·전문가 큐레이션, 공개 컬렉션과 내 컬렉션 관리에 접근한다. `/archive` URL과 개인 기록은 유지된다.
- 알림·메시지는 준비 안내만 제공한다. 이모지 미니게임과 서버 히든 블록 퀴즈는 각각 기존 경로를 유지한다. AI 호출·DB migration·유료 서비스 추가는 없다.
- 기존 다른 화면과 인증 흐름을 전면 리디자인하지 않는다. 검색 화면에는 홈에서 제목을 넘기는 딥링크만 추가했다.
