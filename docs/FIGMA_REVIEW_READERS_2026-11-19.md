# Figma 빨간 박스 — 완료 리뷰 읽기 화면

## 승인 범위

- 사용자가 보안 작업 중지를 요청했다. Daybreak를 사용하지 않으며 이번 변경은 Figma의 빨간 박스 안 완료 리뷰 읽기 화면만 대상으로 한다. 의존성·요금제·메일·운영 데이터·권한 정책은 변경하지 않는다.
- Figma `7o0aA5nN2muGSgSEdtsYw7`, page `0:1`, 빨간 테두리 `43:495`. Light 참고 화면 `43:327`/메모 `43:461`, Core 참고 화면 `43:462`/메모 `43:494`의 실제 속성과 원본 스크린샷을 읽어 구현했다.
- 메모의 핵심: Light 완료 리뷰는 상단 키워드와 하단 작성 리뷰, Core는 사진과 텍스트가 이어지는 블로그형 읽기. 두 화면 모두 기록 완료 버튼과 부가 안내 문구를 제거한다. 참고 프레임에 남은 작성 UI보다 이 메모가 우선이다.

## 구현

- 기존 `/review/[id]`를 완료 기록 읽기 화면으로 통합한다. 자신의 나만 보기 기록은 기존 소유자 조회로, 다른 사용자의 기록은 기존 전체 공개·완료 조회로만 읽는다. 작성 중 초안은 읽기 화면에 노출하지 않는다.
- 완료 기록의 기본 진입: 기록 목록·마이 캘린더·기존 기록 목록 → 읽기. Light/Core 작성 완료 → 저장 성공한 해당 기록 읽기. 초안은 기존 편집기를 그대로 연다.
- 본인에게만 상단 연필을 제공하고 기존 Light/Core/이전 기록 편집기로 연결한다. 읽기 화면 자체에 본문 저장·삭제 입력 기능을 추가하지 않는다. 계정과 기록 ID를 기준으로 화면 상태를 분리한다.
- Light: 402px 프레임/21px 바깥 여백/17px 모서리, 영화 요약·정확한 반별점·대표 키워드·질문별 실제 답변·작성한 본문. 선택 해제한 대표 키워드를 임의 복원하지 않으며, 건너뛴 질문은 표시하지 않고 원래 질문 번호는 유지한다. 입력창·마이크·문자 수·AI 추천 안내·완료 버튼 없음.
- Core: 402px 프레임, 사진 전체 폭/402:259 비율, 본문 좌우39px, 20/26px 제목·15/20px 기본 본문·문단20px 간격. 기존 굵게/기울임/목록/인용/글자 크기를 유지한다. 본문 사진은323:184 비율로 화면 폭에 맞춘다. 사진 없는 기록에는 가짜 사진이나 업로드 버튼을 넣지 않는다.
- 기존 SVG 뒤로/연필/별/화살표와 실제 영화·Storage 사진을 재사용한다. Figma 샘플 영화·문장을 실제 기록으로 하드코딩하지 않는다. 브라우저에 가짜 iOS 상태바·홈 바를 그리지 않는다.
- 공개 기록의 공감·보관·댓글·답글·본인 댓글 삭제·신고는 글 아래 별도 영역에 유지한다. 비공개·데모 기록에서 공개 커뮤니티 RPC를 실행하지 않는다. 댓글 조회 실패가 본문 읽기까지 막지 않는다.
- 작성 중 AI 동의·저장 전 검토·스포일러·공개 범위와 필수 입력 검증은 유지한다. 전시 게스트 `/exhibition`과 무료 AI 한도·11/24 00:00KST 운영 종료 설정은 변경하지 않는다.
