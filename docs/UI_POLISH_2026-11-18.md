# 2026-11-18 앱 문구·모바일 레이아웃 정리

## 사용자 요청과 범위

사용자가 제공한 실제 휴대폰 사진 3장을 기준으로, 앱 전반의 불필요한 보충 설명과 개발·운영 용어를 정리하고 카드 경계·모서리·간격을 수정한다. 발표 자료/PPT/PDF와 기존 운영 데이터는 변경하지 않는다. 검증 후 기존 GitHub와 EAS Hosting `beta`에 게시한다. 유료 기능·새 배포 대상·DB 권한 변경은 없다.

## 문구 기준

- 제거: ‘안전한 공개 기록’ 권한 설명 배너, ‘첫 댓글을 남겨보세요’, 반복되는 집계 방식·DB 적용·서버 연결 설명, 편집 도구의 상시 사용 설명, 단계 번호(5D/5E), 생성형 AI 면책 문구의 무조건 반복 표시.
- 간결화: Core 입력 예시, 대표 키워드 안내, 추천 비율 안내, 데모·샘플 표시, 로그인 게이트, 큐레이션 작성자 표시.
- 유지: 필수 동의와 외부 AI 전송·Google 개선 활용 안내, 공개 범위 선택, 스포일러, 실제 오류/복구/미입력 안내, 탈퇴·초안 교체 등 손실 경고, 익명 응답의 열람 범위, TMDB/JustWatch 출처, 전시 게스트 세션·보관 안내.
- 실제 주간 랭킹이 없을 때는 ‘지금 눈여겨볼 영화’, 키워드 집계가 없을 때는 ‘영화를 만나는 키워드’로 표시한다. 샘플을 실제 사용자/전문가 기록이나 실제 순위로 오인시키지 않는다.
- 리포트의 상세 계산 기준은 별도 상세 페이지에서 펼쳐 확인한다. 유형 알고리즘·점수 계산은 바꾸지 않는다.

## 구조 수정

1. `HomeReviewCard`: 본문에만 걸려 있던 절대 좌표 테두리를 제거하고, 키워드와 반응 버튼까지 포함하는 바깥 카드에 실제 테두리를 둔다. 내용 높이와 키워드 줄바꿈에 따라 늘어난다.
2. 키워드: 긴 단어는 카드 안에서 줄바꿈한다. 반응 영역과 12px 간격, 버튼 터치 영역은 최소 44px다. 미집계 조회수의 빈 아이콘은 제거한다.
3. 매거진 표지: 업로드 사진과 TMDB/샘플 이미지 모두 동일한 20px 모서리 안에서 자른다.
4. 좁은 화면: 홈·보관함 매거진 폭은 `min(화면 내용 폭 - 42, 311)`, 탐색 컬렉션 폭은 `화면 내용 폭 - 42`로 맞춘다.
5. 리포트: 고정 크기 SVG 사각 테두리를 콘텐츠 크기의 벡터/CSS 경계로 바꾼다. 문구 삭제 후 남는 고정 높이·과한 빈 공간도 제거한다.
6. Light: 중복 미입력 경고를 한 위치에 표시한다. 선택 전 키워드와 작성한 본문은 더 선명하게 표시한다. 검색하기 전 ‘검색 결과 없음’이 잠깐 나타나는 현상을 막는다.
7. 로컬 검수 서버: Expo의 `people/index.html` 출력도 처리한다. 기존 경로 정규화·dotfile 차단·dist 루트 제한·loopback 바인딩을 유지한다.
8. 기존 공통 화면도 로컬 Pretendard를 사용해 서체를 통일한다. 공개 질문·감상 본문은 한글 단어를 묶어 줄바꿈해 마지막 한 글자만 다음 줄에 남는 현상을 줄인다.

## 검증 기록

- 기존 실제 기록은 수정하지 않는다. 별도 `localhost:8084` 데모에서 Light 1편, Core 1편을 비공개로 로컬 저장했다.
- Light: 별점 5점/평가 문구, 미입력 오류, 키워드 선택, 질문 변경 1회/완료 후 비활성, Q2~Q5 건너뛰기, 로딩→종합, 직접 작성→완료→아카이브 1편 확인.
- Core: AI 동의하지 않음→Q1/Q2 직접 답변→기본 작성 가이드→그만하기→매거진 편집→완료→아카이브 총 2편 확인. AI/마이크/사진/운영 게시를 실행하지 않았다.
- 주요 7경로(탐색·마이·리포트·피드 작성·Light 검색·Core 검색·소개4)를 320/402/430/1280px로 점검했다. 문서 가로 넘침은 28조합 모두 0px다. 가로 영화 레일의 다음 카드 일부 노출은 의도한 스크롤이다.
- 홈 리뷰 카드의 320px 측정: 폭 278px, 대표 키워드와 반응 버튼이 바깥 카드 안에 위치한다. 키워드 5개가 두 줄로 바뀌어도 테두리가 늘어난다.
- 실제 로그인 계정에서 기존 8편/취향 유형이 조회되는 것을 확인했다. 다른 작성자의 ‘더 배트맨’ 공개 기록에서 제거 요청한 배너·빈 댓글 문구가 없고, 기록 수정/삭제 버튼은 0개다. 댓글·공감·저장은 누르지 않았다.
- 실제 공개 카드도 320px에서 리뷰 278px, 매거진 표지 x21~299px·폭278px·모서리20px로 측정했다. 공개 리뷰의 320/402px에서 문서 가로 넘침0px, Pretendard와 `keep-all` 적용도 확인했다.
- 설정·프로필 편집·분석 상세·컬렉션·멤버 탐색·연결·알림·설치·퀴즈 등 부가 경로도 확인했다. 실제 계정이 필요한 빈 상태와 데모 상태를 구분한다.
- 자동 검사: TypeScript/lint, 원본 벡터 검사, 비밀정보 source/build 검사, 42파일/318테스트, 정적 웹 48경로 빌드 통과.
- 첫 이미지 디코딩 중 포스터 일부만 나타난 소개4 캡처는 최종 증거에서 제외하고, 4장 모두 로딩 완료 확인 후 다시 캡처했다. 일부 초기 검색 캡처는 데이터 준비 중 화면이므로 최종 빈 상태 증거로 쓰지 않는다.

로컬 화면/반응형 측정은 Git에 게시하지 않는 `tmp/ui-polish-20261118/`에 보관한다. `responsive-matrix.json`, `matrix-sheet-*.png`, 카드 before/after 및 단계별 이미지가 있다. 빨간 사각형 키보드 포커스는 접근성 표시이지 테두리 오류가 아니다.

실제 iPhone Safari·Android 기기, OS 키보드/마이크/사진 권한과 모든 사용자 데이터 길이의 완전한 픽셀 동일은 보장하지 않는다. 이번 변경은 프런트엔드 표현·레이아웃이며 무료 AI 운영 기한이나 전시 입장 상태를 열지 않는다. 기존 보안 경계와 권한 회귀 테스트를 유지한다.

GitHub CI [44309646087](https://github.com/hoya0328/flick/actions/runs/44309646087)는 기존 의존성의 npm 감사에서 실패했다. 로컬 TypeScript/lint/318테스트/빌드 성공과 별개이며, CI 전체 성공으로 안내하지 않는다. npm은 전이 의존 경로를 포함해35건(high34/moderate1)을 보고했다. 독립된35개 원인이라는 뜻은 아니다.

- `picomatch`: [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf), 2026-11-17 갱신,4.0.7 이하 ReDoS이며 확인 시 수정 버전이 없다. Expo/Metro/Vite/Vitest 등의 전이 경로에 전파된다.

- 이번 UI 작업은 의존성을 새로 추가하거나 `package.json`/lockfile을 변경하지 않았다. SDK 강제 변경·Vitest 강제 다운그레이드·감사 기준 낮추기/예외 무시는 하지 않았다. 별도 의존성 보안 보완에서 node-forge 호환 패치와 picomatch의 공식 수정/검증된 완화 방식을 검토해야 한다.
