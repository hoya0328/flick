# 졸업 전시 운영·무료 한도·비용 검토

기준일:2026-11-05 KST. 사용자 조건은 약7일, 하루100명 미만(산정 상한700명), 한 사람 영화1편 체험. 본 문서는 **검토이며 개발/과금 전환 승인이 아니다**. 설정·키·DB 정책·데이터·배포는 변경하지 않았다. 진단 SQL은 읽기 전용 `supabase/tests/exhibition_capacity.sql`이다.

## 결론

- DB/텍스트 기록은 현재 규모상 Supabase Free 유지가 합리적이다. 하루 인원 확정 보장이 아니라 월간 사용자·용량·전송량·동시 부하 조건이다.
- Gemini는 실제 프로젝트 Free에서15 RPM,250,000 input TPM,500 RPD를 확인했다. Light 위주면700명/주도 무료권 안에서 설계 가능. 모두 Core5문답이면84명/일부터6호출×84=504로 초과할 수 있다.
- AI 품질/완주를 행사에서 보장하고 싶다면 **DB는 Free, AI만 행사 총 $5~15 예산(여유 $20)**을 검토할 수 있다. 유료 활성화·새 결제·서버 허용 정책 변경은 별도 승인과 재검증이 필요하다.
- 현재 그대로 전시하기보다 회원가입 이메일 경로/전시용 체험 진입·AI 총량/사진 제한·12유형의 최소 기록 수·연령/개인정보 조건부터 정리해야 한다.

## 화면 질문 수와 API 호출 수

질문 변경/초안 재생성/재시도/별도 원문 의미 분석을 하지 않고 동의한 실제 계정이1편을 끝내는 기준이다. AI 미사용/현재 데모는 질문을 보여도 Gemini를 호출하지 않는다.

권장 무료 운영 목표는최대400호출/일·12호출/분 등20%여유 확보. 이것은 **제안**이며 현재 설정이 아니다. 한도는 API키별이 아니라 프로젝트 공유다. 한 사람이 여러 편 쓰거나 Core 질문을 변경하면 소비가 늘며 동시에15개 이상 요청이 몰리면 하루 여유가 있어도429가 날 수 있다. 일 한도는 Pacific 자정 초기화로 한국 자정과 다르다.

앱 자체의 현재 계정별 제한은 question20/일·6/분, draft5/일·2/분이다. 같은 전시용 공유 계정1개로 모두 쓰면 약4개의 Core5문답 후 질문20회에 걸릴 수 있으므로 **관리자/공유 계정으로 관람객을 받지 않는다**. 개인 또는 별도 익명 세션이 필요하며 현재 브라우저 데모는 실제 AI/서버 저장 체험이 아니다.

추가 Core 원문 의미 분석은 요청당 AI1회 추가, 현재 앱 전체30회/일·계정5회/일·2회/분이다.700명 전원에게 같은 날 제공하는 기능이 아니다. 기록된 무료 확인 만료일11월3일도 지났으므로 실제 서버 상태를 전시 전에 재확인하고 승인 후 갱신해야 한다. 현재 무료 등급을 읽었다고 설정을 자동 갱신하지 않았다. 기본12유형 통계는 AI 호출이 없으며 임시 유형부터도 서로 다른 유효 영화3편이 필요하다(대표 유형은8편부터 추가 기준).

## 비용 산식 / 선택

현재 Gemini3.5FlashLite 표준 text API 단가는 입력$0.30/100만토큰·출력(추론 포함)$2.50/100만토큰. 검색 grounding/이미지/음성 서비스는 견적에 없다. API 유료는 Gemini 소비자 구독과 별개다. 유료 전환 시500회의 무료 사용 뒤 초과분만 결제되는 구조라고 가정하지 않고 전체 사용을 유료 단가로 산정한다.

`비용 = 입력토큰/1,000,000×0.30 + 출력토큰/1,000,000×2.50`

- 현 소규모 로그 평균을 단순 대입한 예시:초안700회 약$0.56,질문5+초안700세션 약$2.86. Light/Core 초안 혼합·과거 질문 방식·짧은 샘플이므로 예측 보장은 아니다.
- 더 긴 Core를 세션당 입력10,000~20,000/출력3,500~6,000토큰으로 가정하면700세션 **$8.23~14.70**. 질문 변경/재생성·오류/추가 분석은 별도다. 행사 예산$5~15, 여유$20 제안은 이 가정이지 확정 청구액이 아니다.
- 선불 최소액은 공식 문서상$5(실제 지역/계정 UI 우선). 자동 충전/프로젝트 지출 상한·서버 요청 상한이 필요하며 선불/지출 상한에도 약10분 집계 지연 초과가 가능해 ‘충전액=절대 최대 청구’라고 보장하지 않는다. 현재 Free에서는 한도 초과 시 자동 유료 전환하지 않는다.
- DB는0원 예상. Free50,000MAU·500MB DB·1GB Storage·5GB egress·500,000Edge invocations/월과700명 규모를 비교하면 사용자 수만으로 Pro가 필요하지 않다. 텍스트1건당50~100KB라는 계획 가정이면700건35~70MB 증가이나 인덱스/로그/추가 영화 캐시/미디어 전송·부하에 따라 달라진다.
- Supabase Pro는 선택적으로월$25부터(첫 프로젝트 기본 구성,조직 내 추가 프로젝트/compute/세금 별도). 행사7일이라고 월요금을 단순1/4로 계산하지 않는다. 가격 인상만으로 앱 사진160/원문 분석30 제한과 이메일 SMTP 문제가 해결되지 않는다.
- Expo는 Free 잔여량 내0원 예상.700명×100Hosting 요청=70,000회라는 가정은 월100,000보다 작지만 실제 요청/기존 사용량은 미확인이다. 정적 JS/이미지도 요청 수에 영향을 주므로 방문자=요청1회가 아니다. 필요하면 Starter월$19+초과 사용료를 검토하되 현재 변경할 이유는 확정하지 않았다.
- 이메일은 Supabase 기본 SMTP가 외부 비팀원 발송을 제한하고2통/시간이므로 전시용 가입 경로로 쓰기 어렵다. 무료 custom SMTP 예:Brevo300통/일(transactional 포함),Resend100통/일·3,000통/월.100명 가까이 받으면 재발송/비밀번호 재설정까지 더해 Resend일100은 여유가 적다. 도메인·발신 검증·계정 승인·SMTP/Auth 자체 분당/시간 제한도 별도 확인한다. Supabase Pro 구매만으로 custom SMTP가 자동 설정되지 않는다.
- 원화 예산을 적을 때는 편의상$1=1,400원 **가정**이면AI$5~15=7,000~21,000원,Pro$25=35,000원. 실시간 환율/세금/카드 수수료는 반영하지 않았다.
