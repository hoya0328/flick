# PROJECT CONTEXT

## 한 문장 정의

FLICK는 사용자가 감정 키워드로 다음 영화를 발견하고, 감상 직후의 느낌을 가벼운 기록 또는 AI 비평 가이드로 남겨 자신의 영화 취향과 기억을 축적하는 모바일 서비스다.

## 핵심 기획

- 1차 사용자(Light): 긴 리뷰는 부담스럽지만 당시의 감정과 취향은 오래 남기고 싶은 20~30대 관객
- 2차 사용자(Core): 영화의 연출·미장센·서사 등을 구조적으로 분석하고 자신의 관점을 발전시키고 싶은 관객
- 핵심 문제: 기존 평점·한줄평은 감상의 결을 보존하지 못하고, 장문 리뷰는 작성 부담이 커 기록이 지속되지 않는다.
- 사용자의 일: “지금 내 기분에 맞는 영화를 고르고, 본 뒤의 느낌을 힘들이지 않고 내 언어로 남기고 싶다.”
- 가치 제안: 키워드 기반 발견과 단계형 감상 기록을 연결해 선택과 회고를 하나의 습관으로 만든다.
- 차별점: 장르·별점 중심 추천보다 감정 키워드를 앞세우고, AI가 완성물을 대신 쓰기보다 영화 요소를 생각하게 하는 질문·키워드 정리·초안 생성을 보조한다.
- MVP 결과: 사용자가 영화 한 편을 발견하거나 등록하고, 감상 후 3분 안에 의미 있는 기록을 완성해 다시 찾아볼 수 있다.
- 북극성 지표: 월간 의미 있는 감상 기록 완료 수. 의미 있는 기록은 별점과 최소 3개 감정 질문 또는 100자 이상의 본문을 포함한 저장 건으로 정의한다.

## 제품 루프

1. 사용자가 현재 감정 또는 선호 키워드를 선택한다.
2. FLICK가 키워드와 기존 기록을 바탕으로 영화를 추천한다.
3. 사용자가 감상한 영화를 확인하고 기록 방식을 고른다.
4. 가벼운 질문 또는 자유 작성으로 감상을 입력한다.
5. AI가 대표 키워드와 정리 초안을 제안하고 사용자가 승인·수정한다.
6. 기록이 캘린더와 취향 리포트에 쌓여 사용자의 성취를 보여주고 다음 추천을 개선한다.

## MVP 범위

### 반드시 포함

- 키워드 중심 온보딩과 초기 취향 설정
- 영화 검색, 상세 정보, 키워드 기반 추천
- 감상 완료 영화와 감상일 등록
- `가볍게 기록`: 별점과 단계형 감정 질문, 대표 키워드 정리
- `집중해서 기록`: 자유 본문 작성, 영화 요소별 AI 비평 질문과 정리 초안, 최종 수정 권한
- 개인 기록 목록·캘린더
- 취향 리포트 1차 버전: 자주 사용한 키워드, 감정 TOP 3, 별점 분포, 기록 유형별 요약
- AI 생성·수정 범위 표시, 비공개 기본값, 삭제 기능

### MVP 이후

- 공개 피드, 팔로우, 댓글, 좋아요, 스크랩
- 매거진형 고급 편집과 전문 큐레이터 채널
- 티켓 카메라 스캔/OCR
- 주간 인기 순위와 정교한 소셜 추천
- 리포트 공유 카드, 배지·보상, 고급 비교 분석

### 명시적 비목표

- 영화 스트리밍 또는 예매 플랫폼
- 영화 DB 전체를 직접 운영하는 사업
- AI가 사용자 동의 없이 리뷰를 자동 게시하는 기능
- 출시 초기의 광고·구독·크리에이터 수익화

## 성공 지표

- 활성화: 가입 후 24시간 내 첫 의미 있는 기록 완료율
- 지속성: 첫 기록 사용자의 4주 내 두 번째 기록 완료율
- 기록 효율: 기록 시작 대비 완료율과 완료까지 걸린 중앙값
- 추천 가치: 추천 상세 조회 및 감상 목록 추가율
- 신뢰: AI 초안 수정률, 비공개 전환율, 신고·삭제 요청률

초기 목표치는 사용자 테스트와 2주 클로즈드 베타의 기준값을 확인한 뒤 정한다.

## 주요 가정과 위험

- 감정 키워드가 장르·평점보다 선택을 쉽게 만든다는 가정이 아직 검증되지 않았다.
- 질문 수가 많으면 기록 완성도가 아니라 이탈만 높일 수 있다.
- AI 비평 질문과 초안이 사용자의 목소리를 지우거나 사실과 다른 해석을 만들 수 있다.
- 외부 영화 데이터·포스터·예고편 사용에는 API 계약과 저작권 검토가 필요하다.
- 공개 커뮤니티는 콜드스타트, 스포일러, 악성 댓글, 개인정보 이슈를 동시에 만든다.

## 검증 계획

- 5~8명 대상 프로토타입 테스트로 영화 선택과 기록 완료 시간을 측정한다.
- 동일 영화에 대해 `키워드 질문형`과 `빈 글쓰기형`의 완료율·만족도를 비교한다.
- AI 초안 전후의 수정량과 “내 글처럼 느껴지는가”를 확인한다.
- 커뮤니티 없이 개인 기록만으로 4주 재방문이 발생하는지 먼저 검증한다.
