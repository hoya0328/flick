## 기능 보존 및 상태

- 기존 이메일/비밀번호 signIn, 닉네임 포함 signUp, 비밀번호 재설정, 이메일 확인 필요/즉시 세션 생성 결과, 검증된 공유 링크 복귀를 유지한다. 서버 SessionProvider/DB/정책/이메일 공급자/AI/전시 기한 변경 없음.
- 필수 입력/유효성 검사 실패 시 첫 누락 필드로 스크롤·포커스하고 바로 아래 안내한다. 비밀번호 불일치도 확인 필드로 이동한다. 서버 결과 안내도 화면에 보이도록 스크롤하며, 통신 오류는 한국어로 표시한다.
- 모드 전환 시 이메일/닉네임은 유지하고 비밀번호2칸·오류는 비운다. 처리 중 재요청·모드 전환을 잠그며 실패 후 입력을 다시 허용한다. 비밀번호를 저장소·로그·URL에 추가하지 않았다.
- 이메일 발송 제한/SMTP 보류 등 기존 운영 조건은 그대로다. UI 변경을 실제 이메일 전달 성공이나 인증 정책 변경으로 설명하지 않는다. 기존 11/24 00:00KST 전시 종료 설정도 변경하지 않는다.
