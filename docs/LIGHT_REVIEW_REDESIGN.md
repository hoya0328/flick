## 저장·복구

`reviews.light_flow`에는 버전, 질문별 answered/skipped, 변경 사용 여부, 좋았던 요소, 대표 키워드와 초안 출처를 저장한다. 질문·선택 태그는 기존 snapshot 테이블을 재사용한다. 새 `save_light_review` RPC는 기존 소유자 검증 writer를 재사용하고 전체를 하나의 트랜잭션으로 저장한다. 구형 Light/Core RPC와 기록은 유지한다.

입력은 직렬 큐로 기기에 임시 보관한다. 다른 기기에서 이어 쓰려면 안내 메뉴의 **초안 저장**을 누른다. 완료 기록의 수정 내용은 작성 완료 전까지 서버 원본을 바꾸지 않는다. 새 기록 편집은 `/light-record`, 구형 기록은 기존 편집기로 연결한다.
